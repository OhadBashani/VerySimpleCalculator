# Console Calculator in C#

A robust and interactive C# Console Application that acts as a basic arithmetic calculator. It includes input validation, error handling (such as division by zero protection), and a continuous replay loop.

## Features
- **Basic Arithmetic Operations:** Supports Addition (`+`), Subtraction (`-`), Multiplication (`*`), and Division (`/`).
- **Robust Input Validation:** Uses `double.TryParse` to prevent application crashes when users enter invalid text or letters instead of numbers.
- **Division by Zero Protection:** Safely catches and handles attempts to divide by zero with a friendly error message.
- **Continuous Loop:** Allows users to perform multiple calculations in a single session and choose when to exit.

## Prerequisites
- [.NET SDK 6.0 / 7.0 / 8.0 / 9.0](https://dotnet.microsoft.com/download) (or Visual Studio)
